# Repository Guidance

## Scope
These instructions apply to the entire repository.

## Conventions
- Prefer Python's `logging` module over `print` statements for runtime messages.
- When documenting code, include clear, pedagogical comments that explain the intent of each step.
- Keep README content concise and actionable, focusing on how to run the processing scripts and what data they expect.

## Testing
- Document any command you run in the final summary under the **Testing** section.
